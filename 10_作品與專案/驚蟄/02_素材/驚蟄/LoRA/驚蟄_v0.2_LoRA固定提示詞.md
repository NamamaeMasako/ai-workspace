# 驚蟄 v0.2 LoRA 固定提示詞

> 建立日期：2026-07-27
> 狀態：歷史 v0.2 視覺參考；與 `jingzhe-animagine-v0.2.safetensors` 一起使用，不得直接認列為 v1.0 遊戲立繪。
> 目的：補強 LoRA 單獨使用時不穩定的服裝顏色、角色核心特徵與蝗蟲紋約束。

## 使用原則

- 「固定核心提示詞」每次都保留，只替換構圖、表情、姿勢與道具等變動欄位。
- 服裝顏色補強詞與對應 negative 不可省略；2026-07-27 的五張診斷測試顯示，加入後深色和服穩定度明顯提高。
- 蝗蟲紋提示詞只能提高正確率，不能像版型或 ControlNet 一樣保證精確數量、位置與朝向。
- 正式圖仍須依正面版位參考圖篩選；不符時重抽、局部重繪或後製，不把生成誤差視為新設定。
- 提示詞中的左／右一律以角色自身方向為準。

## 2026-07-27 測試結論

- 原始 LoRA 對深色和服的約束不足，服裝可能漂成白色、淺色或黑白拼色。
- 加入 `black yukata, dark clothing, monochrome black outfit`，並在 negative 排除白色、淺色與雙色和服後，五張診斷圖約四張維持可接受的深色服裝。
- `based on approved reference` 或 `exact fixed placement based on reference` 這類句子在沒有實際載入參考圖時不具控制力，因此不作為版位保證。
- 蝗蟲紋的精確數量與版位仍需人工篩選或局部修正；固定提示詞的作用是降低錯誤率，不是完全鎖死圖案。
