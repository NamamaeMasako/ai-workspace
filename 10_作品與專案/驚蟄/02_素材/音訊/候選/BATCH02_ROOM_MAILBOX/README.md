## 觸發與接續

1. 「煙草點燃時」沿用已採用 SFX13 點火，單次音量 0.8；下一句接新 SFX14 抽吸，使用 queue 避免提前點讀下一句時立即截斷點火。
2. 郵箱 event 顯示前播放一次 SFX16，讓短共鳴與 dissolve 一起進場。這是特寫的音效提示，不改寫成郵箱此時才首次出現在桌上的新事件。
3. 「一頁紙折起，放進郵箱」先播摺紙、留 0.10 秒，再接開蓋；下一句將關蓋排進同一 sound 佇列，避免關蓋 play 直接切掉前一動作。沒有新增強制閱讀 pause。
4. 「合上筆記本」單次播放筆記本變體。窗外蟲鳴只由文字表達。
5. 「門外傳來很輕的腳步聲」播放一次木板腳步，夢見送茶與談話留給既有 BGM，未增加文字沒有發生的開門、茶壺落桌或人聲。
6. 第三章入口以 0.15 秒停止上一幕可能殘留的 sound，沿用原 BGM04 轉場。

既有 BGM03 的配樂、播放配置與使用者音量偏好保留；全部持續非 BGM 環境音保持停用。音效經既有 sound／sfx mixer 及設定頁「音效音量」控制。

## 製作與紀錄

- 七個檔案均為原創程序合成：濾波噪聲、紙／氣流包絡、木質模態與短共鳴。未使用外部錄音、音效庫、生成模型或人聲。
- 每個固定 seed、參數、峰值、WAV／OGG 雜湊與格式見同名 JSON 及 `generation_manifest_take01.json`。
- 48 kHz 單聲道 PCM 24-bit 母檔，44.1 kHz 單聲道 Vorbis q6 遊戲副本；皆為非循環短音效。起落平滑，固定峰值、不以動態 loudness normalization 拉大音量。
- 可編輯來源：`../../母檔/BATCH02_ROOM_MAILBOX/produce_batch02_take01.py`，需要 Python、numpy、scipy、ffmpeg／ffprobe。既有 take 不覆寫。
- 實際觸發、遊戲檔案雜湊及起點觀察見 `scene_integration_take01.json`。本批已由生前回覆「OK，繼續」核可，正式紀錄見 `formal_adoption.json`。
