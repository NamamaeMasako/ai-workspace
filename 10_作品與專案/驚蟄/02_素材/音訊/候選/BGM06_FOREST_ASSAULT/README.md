## take03 製作紀錄

- ACE-Step 1.5 Turbo 直接擴散 text2music、thinking=false、8 steps，不使用 LM audio codes。四首 seed 3321–3324，節奏提示分別為 128／132／140／124 BPM，E minor、4/4。這些是生成提示，不是已量測的實際 BPM。
- 撤掉 take02 的慢速長音主導、稀疏鼓點及大段停頓；改要求立即進入交戰、快速持續的低弦運弓、密集鼓點、短促錯位重音及半音／增四度張力。配器描述放在提示前段，避免差異被長篇共同描述沖淡。
- 新生成四首，不對舊檔單純加速；不以慢速 take02 音檔作參考，以免保留不合適的節奏結構。選定本輪短版後，長版仍須以選中音檔作 reference_audio。
- 原始 WAV 25 秒，試聽取前 20 秒、30 ms 淡入與末尾 0.5 秒淡出；先以 loudnorm 處理，再依實測音量作固定增益匹配與 -2.5 dBFS 峰值限制、延遲補償。處理前 OGG 保留為 `_premaster.ogg`，同名 JSON 記錄前後資料與實際成品格式。
- WAV 母檔位於既有 `母檔/BGM06_FOREST_ASSAULT/`；本資料夾保存 44.1 kHz 立體聲 Vorbis q5 OGG、同名 JSON、`generation_manifest_take03.json`、`technical_check_take03.json`。新版名稱附 `_take03`，不覆蓋舊音檔。

- 改用 ACE-Step 1.5 Turbo 直接擴散 text2music，thinking=false，不使用 0.6B LM 的 audio codes；8 steps、seed 3311–3314。此為處理方向，不能斷言首輪歡樂感僅由 LM 引起。
