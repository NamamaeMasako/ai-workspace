# 第五批：第七章林間交戰

2026-10-19：生前核可第四批並指示「OK，繼續」。四條交卡路線的林間交戰已接入九個基礎 Cue、兩個變體，共十一個新短音檔及四個沿用檔，待完整場景試聽核可，尚未正式採用。

## 試聽方式與範圍

本次開啟臨時試聽選單，可直接選第一／第二輪「交給花見」或「交給夢見」。每段從交卡起，經林道、召喚與交戰，播完回到試聽選單。

- 交給花見：檢查至蟲影逼退土蜘蛛、正式故事即將切到「另一邊，月下庄靜得像沒有住人。」之前。
- 交給夢見：檢查至髮切追擊、切斷絲影、交戰停曲之前；不進入花見死亡與回退。
- 月下庄遇襲、返庄、死亡與回退屬第六批；第八章屬第七批。
- 四個試聽段落直接取自已整合的 `script.rpy`，台詞、演出、音效與 BGM 命令保持相同。臨時選單只供這次檢查，透過外部 search path 與引擎 after_warp hook 啟用；正式遊戲仍循原路線流程。片段來源與 SHA-256 見 `scene_review_manifest_take01.json`，可編輯建置來源 `../../母檔/BATCH05_FOREST_BATTLE/prepare_scene_review_take01.py`。

## 按實際出現順序確認

### 四條路線共通的前段

1. **交卡的紙布摩擦與淡共鳴**：「驚蟄從袖中取出那張黑色卡片，交到……手裡。」沿用收卡紙布聲 0.85，再排入黑卡共鳴 0.7。
2. **收卡入衣**：收下卡片的句子，沿用紙布聲 0.8。
3. **林道濕地腳步與餘燼**：「林道很黑，只有煙斗的火光在一點一點前行。」短濕葉行走後接沿用餘燼 0.75，沒有循環環境音。
4. **吹起煙草**：「他吹起煙草。」新吹氣變體，與已採用吸菸聲分開。
5. **式神召喚**：髮切、大百足召喚 CG 出現時，一次暗色匯聚與短蟲翼質感。
6. **土蜘蛛逼近與短嘶聲**：現身句播放大型重步；下一句地面微震／影子壓下時接一次短嘶聲。

### 接著：交卡給花見的路線

7. **髮切鐮刃交錯**：「髮切先衝上去，鐮刃交錯……」
8. **蛛腳拍地**：「牠的節肢拍地，揚起一層灰。」重步變體 0.9。
9. **大百足甲殼移動 → 衝撞**：「大百足自側面猛撞……」同一動作佇列接續。
10. **薙刀揮動 → 命中甲殼**：「花見趁空隙切入……割出白痕。」刃風後留 0.04 秒再接命中。
11. **蟲影纏住視線**：「驚蟄的蟲影纏住牠的視線……」同召喚音弱化至 0.45，之後本段返回選單。

### 接著：交卡給夢見的路線

7. **髮切鐮刃 → 大百足甲殼 → 衝撞**：「髮切牽住牠的正面，大百足自側面猛撞。」三個短聲在同一 sound 佇列依序播放。
8. **薙刀揮動**：「她的攻勢猛烈，卻也留下空隙。」此處未描述命中甲殼，只播揮動。
9. **蛛絲細響 → 肩側切割**：絡新婦現身時沿用 SFX22；「一抹細影掠過花見的肩。」配切絲聲 0.65。
10. **蛛腳拍地**：「牠的節肢拍地……把視線切碎。」重步變體 0.9。
11. **土蜘蛛倒下**：甲殼衝擊音弱化至 0.55，非人類倒地聲。
12. **髮切追擊 → 切斷絲影**：追擊時鐮刃聲 0.85，下一句「鐮刃一閃，黑影斷成幾截……」接切絲聲，之後本段返回選單。

第二輪保留各自額外對白的間距，聲音仍放在實際動作句子。請連同既有 BGM05 → BGM06 一起確認自然感、力道、時機與音樂搭配。以上為製作意圖，不宣稱助理獨立人耳驗收。
