## 使用場景

- 第七章兩輪花見同行路線：森林交戰中切到月下庄，絡新婦在屋內搜尋、夢見提燈查看並遭到襲擊。
- 隨後回到森林，花見戰後仍感不安、擔心夢見，直到返庄途中延續同曲。
- 庄門口實際反擊切回既有 BGM06；確認死亡與悲痛的段落另由 BGM11 規劃。

目標是陰森、像恐怖片般逐漸逼近的不安，讓讀者感覺危險已經潛入屋內；不是悲傷哀悼，也不是快速戰鬥。這是製作意圖，實際聽感由生前試聽判斷。

## 製作與來源

- 本機 ACE-Step 1.5 Turbo，`text2music`、`thinking=false`、8 steps；四首為新曲，未引用或上傳既有音樂。
- 生成 25 秒完整原始 WAV 並保留，審聽取前 20 秒，淡入 0.03 秒、淡出 0.5 秒。原始母檔未套審聽淡出，供選定後保留自然尾音及延伸。
- 固定增益與峰值限制整理審聽音量，輸出 44.1 kHz 立體聲 Vorbis OGG；保留 premaster、48 kHz 無損審聽母檔、完整請求／回應、SHA-256 及音量量測。
- 純音樂，提示明確排除人聲、風雨、昆蟲、腳步、木響及其他環境底聲。
- 可編輯來源：`../../母檔/BGM10_INN_HUNTED/produce_shorts_take01.py`。執行需本機 ACE-Step API、Python、ffmpeg／ffprobe；既有輸出不覆寫。
