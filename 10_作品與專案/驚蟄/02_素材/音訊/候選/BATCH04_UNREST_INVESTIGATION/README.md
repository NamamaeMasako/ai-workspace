## 與原 Cue 規劃的對照

- 依現行劇本文字修正放置：第四章森林怪物明寫無聲，因此 SFX24 只在第五章門縫蛛腳處作極輕提示；SFX22 放在實際縮回動作，而非靜止白線或無聲落草。

- 第六章是將灰掃入掌心，沒有式神召喚，改用乾燥細物聲，不預製或播放 SFX21 召喚的反向變體。
