## 使用場景與情緒

舊道傍晚行旅 → 抵達月下庄 → 與花見、夢見初次交談，兩段使用同一首。方向為輕鬆、安靜、克制、稍有旅途餘韻，不搶對白；第一章清晨切換既有 BGM02。黑底短引不配樂，所有持續非 BGM 環境聲維持停用。

本輪為新作；先前序章試用主選單 BGM01 已被生前否決，因此未拿該曲作參考。本輪四種配器是生成方向，實際聽感與場景適配由生前審聽判斷。

## 來源與處理

- 本機 ACE-Step 1.5，acestep-v15-turbo、text2music、thinking=false、8 steps，固定 seed，無 reference_audio／src_audio。
- D major、4/4、60／64／60／62 BPM 是模型提示，未宣稱實測速度／調性。
- 每首原始 WAV 25 秒、48 kHz 立體聲浮點 PCM，保存在 `../../母檔/BGM08_ROAD_TO_MOON_INN/`。
- 前三首取前 20 秒；第四首原生成自約 17.878 秒進入近靜音，改取 18 秒。未裁剪 20 秒 OGG 另存 `_untrimmed.ogg`，原始 WAV 保留。
- 試聽版淡入 0.03 秒、淡出 0.5 秒，初步 loudnorm；再以固定增益匹配 -16 LUFS、-2.5 dBFS limiter（5 ms attack／50 ms release、延遲補償）及重建時間戳，編為 Vorbis q5、44.1 kHz 立體聲。
- 最終 OGG 實測值見表與 `technical_check_take01.json`。4/4 完整解碼無錯誤輸出；無低於 -45 dB、持續至少 0.5 秒的近靜音。這是檔案格式與尾白處理紀錄，不代表聽感已核可。
- 每首完整請求／回傳、處理參數、原始 WAV、各 OGG 的 SHA-256 存於同名 JSON 與 `generation_manifest_take01.json`。`_premaster.ogg` 保留音量匹配前的版本。
