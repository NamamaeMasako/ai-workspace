# BGM11 死亡與悲痛：四首短版 take01

2026-10-16：接續已正式採用的 BGM10，已完成四首 20 秒的新方向，待生前挑選；尚未長版、循環或導入遊戲。

## 使用場景

- 第七章花見同行路線：回月下庄確認夢見死亡，花見跪地、壓抑哭聲，驚蟄無言陪伴。
- 夢見同行路線：確認花見死亡，驚蟄以外衣覆住她、抱起她，帶她回月下庄；同曲先供兩人的死亡與哀悼場景比較。
- 撕卡與時間回退仍預留短暫靜音，下一輪交卡接 BGM05。戰後負傷與救援另由 BGM13 規劃。

目標是悲戚、失去、無力與壓住的悲傷，以小規模配器承接對話。沿用近期回饋中的柔和起音與低聲原則；恐怖懸音並非本曲的核心要求。

## 製作與保留

- 本機 ACE-Step 1.5 Turbo：`text2music`、`thinking=false`、8 steps；四首為新曲，未提供既有音樂作 reference_audio／src_audio，也未使用外部曲目。
- 保留 25 秒原始未套審聽淡出的 WAV；審聽取前 20 秒，淡入 0.03 秒、淡出 0.5 秒。
- 以固定增益整理至約 -27 LUFS 的審聽目標，峰值限制 -16 dBFS，減少突出的起音；實際量測另記，未套用舊版較響亮的審聽音量。
- 保留原始 WAV、20 秒無損母檔、44.1 kHz 立體聲 Vorbis OGG、premaster、完整請求／回應、SHA-256 與量測。
- 可編輯來源：`../../母檔/BGM11_LOSS_AND_REWIND/produce_shorts_take01.py`。需已啟動的本機 ACE-Step API、Python、ffmpeg／ffprobe；既有成品不覆寫。
- 純音樂，提示排除人聲、風雨、昆蟲、木響、腳步等環境聲。
