- 用途：主選單、短開場、主題動機的樂器方向比較。

- WAV 母檔：`../../../母檔/BGM01_LANTERN/instrument_crickets/`，48 kHz。

- 注意：本輪僅為聲音方向候選，尚未做無縫循環、沒有放入遊戲。
