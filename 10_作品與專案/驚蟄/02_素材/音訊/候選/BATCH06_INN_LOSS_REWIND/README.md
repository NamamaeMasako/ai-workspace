## 安靜與演出處理

- 屋簷穿行、無聲抽屜搜尋與細影掠過不配腳步、抽屜或飛掠聲。只有明寫一聲悶響的木框動作新增短音。
- 燈盞未翻倒，只有鈍接觸與燈架微顫，不加玻璃／陶片碎裂。夢見倒下使用SFX31音量0.18；第一輪花見倒下0.55，跪地0.28，放到榻榻米0.22，避免渲染成重摔。
- 第二輪花見已倒在葉上才被看見，該句不重播倒地。耳語、喊叫、喘氣、哭聲與咳血未製作；SFX32咳血留第七批。
- 人物衣料與屍體放下保持低聲；不加入血肉、骨裂或人聲。回退在「風停了一瞬」短淡出sound，保留原BGM淡出與黑底節奏，不新增閱讀pause。
- 50條新聲音命令是本輪唯一遊戲劇本異動；原有每一行文字、演出、音樂及分支均依原順序保留。
- 製作意圖與量測不是人耳聽感核可；兩輪四路線未宣稱已由助理人工驗收。
