固定驗證：
1. Ren'Py lint 無錯誤。
2. Windows ZIP 內必要背景、CG、立繪與字型存在，排除項目不存在。
3. 獨立版不經 SDK 啟動成功並進入序章。
4. 公開版需另外完整測試兩種首次選擇、兩條第二輪路線、存讀檔、自動播放與真結局。
