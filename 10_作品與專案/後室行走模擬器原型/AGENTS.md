# AGENTS.md - 後室行走模擬器原型輕量入口

此資料夾是跨設備入口，不是作品本體或開發工作副本。

## 接手規則

1. 先讀 `@/workspace/AGENTS.md` 與 `@/workspace/10_作品與專案/AGENTS.md`。
2. 再讀本資料夾的 `README.md` 與 `00_導覽與規則/01_獨立repo遷移狀態.md`。
3. 實際工作應進入 `backrooms-walking-prototype` 的獨立 repo；專案遠端與已驗證 commit 見 README。
4. 不要在此重建 `01_文本`、`02_素材`、`03_開發`、`05_成品` 或 `99_封存`，也不要把 clone 放進 OneDrive。
5. 澪主機使用 G 槽工作副本；其他設備必須建立自己的本機 clone，不可照抄澪的絕對路徑。
6. 若只需更新跨設備入口、遷移狀態或 repo 位址，可以修改本資料夾與 `@/workspace/registry/projects.md`。
