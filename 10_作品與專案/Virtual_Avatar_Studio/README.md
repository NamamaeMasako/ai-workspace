# v-skin / Virtual_Avatar_Studio

本專案統一管理虛擬形象，先依角色區分設定、素材、Live2D 工程與發布版本。

## 工作入口

| Codex 對話 | 檔案入口 | 用途 |
|---|---|---|
| v-skin｜專案總覽 | `AGENTS.md`、`00_導覽與規則/00_接續摘要.md` | 專案管理與跨角色共用資料 |
| v-skin｜凜（Rin） | `01_角色/Rin/README.md` | 凜的虛擬形象製作 |
| v-skin｜包子（Baozi） | `01_角色/Baozi/README.md` | 包子的虛擬形象製作 |

Codex 目前以既有 Workspace Project 存取這些資料，角色入口是獨立對話。每次先讀本專案規則與目標角色 README；對話分類本身不提供檔案隔離。

## 資料管理

- `01_角色/<角色名>/`：角色專屬內容。
- `02_共用素材/`、`03_開發工具與流程/`：跨角色共用內容。
- `04_輸出版本/`：跨角色或整包交付版本；單一角色輸出依角色 README 指定入口。
- 外包或委託的來源、用途與限制保留在角色資料中，資料統一存放不代表不同角色或用途可以混用。
