# AGENTS.md - 作品與專案

這裡放生前的作品、遊戲、創作與開發專案。進入任何專案前，先讀本檔，再讀該專案自己的 `AGENTS.md` 或 `00_導覽與規則`。

## 基本規則

- 每個作品或專案應該有自己的資料夾。
- 不要把作品素材直接散放在 `10_作品與專案` 根目錄。
- 若是既有作品延伸、同世界觀作品或共用開發工作區，優先放進既有專案，而不是另開相近的新專案。
- 不確定歸屬時，先放到工作區的待整理位置，或詢問生前。

## 建議專案結構

```text
00_導覽與規則      入口、規則、索引、命名方式
01_文本            劇本、小說、設定、企劃文字
02_素材            圖像、音訊、參考、生成素材
03_開發            程式、工程檔、流程與工具
04_共用參考        專案內部共用的設定或參考
05_成品            可交付、可發布或可展示版本
99_封存            舊版、廢案、備份、待整理資料
```

不是每個專案都要完整使用上述結構；以不混亂、可回溯為優先。
