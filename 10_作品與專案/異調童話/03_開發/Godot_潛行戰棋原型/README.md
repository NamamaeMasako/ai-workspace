# 潛行與戰棋原型

用途：驗證自由探索、背後暗殺、被發現後在同一場景切換回合制戰鬥，以及勝利後恢復探索。使用 Godot 4.6.3 standard；整個場景為固定斜視角 2D 佔位美術，沒有正式故事事件。

## 執行與操作

匯入本資料夾的 `project.godot`，按 F5；或以本機 Godot 執行 `--path <本資料夾>`。程式以 1280 × 800 顯示。

- 探索：WASD／方向鍵自由移動，滑鼠左鍵點地面會自動繞牆尋路。
- 橙色扇形：守衛視野；進入視野且未被牆擋住時，立即進入戰鬥。
- 暗殺：靠近守衛背後，綠色提示出現後停下，按 E，或點右下「暗殺／調查」。暗殺直接解決目標，其他存活守衛仍可發現洛芙。
- 戰鬥：洛芙先行，綠色區域為可移動格；點地面移動，點守衛射擊。每回合有 5 格移動與 1 次攻擊，移動與攻擊可分開執行；空白鍵或右下按鈕結束回合。移動途中不接受其他戰鬥指令。
- 守衛回合：存活敵人依序移動並嘗試射擊。全數解決後恢復探索；洛芙生命歸零時停止遊玩，按 R 重試。
- 右上角文件：探索模式靠近後按 E／右下按鈕取得。可以嘗試完全避開敵人取得文件，也可先解決敵人。
- R／右上按鈕：完整重置。V：顯示或隱藏視野（不改變偵測規則）。

## 建議驗收

1. 從牆下方繞到右半部，接近守衛 A 左側背後，停下暗殺；確認仍是自由探索。
2. 重置後走入 A 右側的橙色視野，確認角色原地進入戰鬥、自由移動停止。
3. 在戰鬥中移動、射擊、結束回合；確認牆會擋路與擋射線、敵人依序行動。
4. 解決所有敵人，確認可重新自由移動並取得文件；也可刻意不攻擊，測試失敗與重置。

## 測試範圍與暫定規則

守衛固定朝向、不巡邏；探索時不搜索、不因屍體報警、沒有聲音、搬屍、掩體命中修正、彈藥或諾亞同行。第一名守衛發現洛芙時，所有存活守衛加入同一場戰鬥，洛芙先手；退出戰鬥需擊敗所有敵人，尚無逃跑規則。守衛移動使用瞬間位置更新，玩家移動有走動過程。這些均是原型簡化，非正式戰鬥定案。

洛芙生命 8、攻擊傷害 2、射程為地面座標的直線距離 5；守衛生命 4、移動最多 3 格、射程 4、傷害 1。步行成本採四向格數，射程採直線距離；目前命中固定成功。視野距離 6、角度 90 度，暗殺距離 1.25，且須位於背後。所有數值可改。

探索與戰鬥使用同一組世界座標及牆壁資料；格狀路徑由 AStarGrid2D 計算，視線由牆壁矩形邊緣線段相交判斷。本原型未使用 RayCast2D；正式場景增加不規則物件時，再評估物理碰撞／射線方案。斜視繪圖是座標轉換，非真實 3D。

## 結構與驗證

- `scripts/EncounterModel.gd`：單一遭遇狀態、角色、視線、路徑、暗殺與戰鬥規則。場景存活期間持有，重置會回復全部狀態；沒有 Autoload、存檔或額外全域管理器。
- `scripts/Main.gd`：輸入、移動演出、敵方回合排程與畫面，不保留第二份生命或戰鬥狀態。
- GUT 9.6.1 複用前一原型已驗證的版本，來源 tag `v9.6.1`、commit `c80954f47bed74a0a2c471d472c0389f98e0a8f6`；授權於 `addons/gut/LICENSE.md`。
- 測試命令：Godot console `--headless --path <本資料夾> --script res://addons/gut/gut_cmdln.gd -gexit`。首次先匯入工程。
- 自動測試涵蓋視野方向／距離／遮擋、偵測切換與位置保留、暗殺範圍與停步、其他守衛目擊、障礙尋路、移動額度、射擊消耗、勝敗及重置。
- 本次 Godot 4.6.3／GUT 9.6.1 實測：13 項測試、69 項斷言全部通過；並透過遊戲視窗實測滑鼠繞牆、按 E 暗殺、被發現切換、戰鬥移動與射擊、敵方回合、勝利恢復探索。守衛生命、洛芙生命與回合狀態均有畫面回饋。

此為玩法操作驗證，與核心循環原型分開；尚未串接日期、正式任務與各結局。沒有設定正式 NPC 出現在此測試場。


## 攻擊範圍顯示

- 洛芙回合且仍有攻擊次數、已停止移動時，地面橙色半透明區域與外框顯示當前射程；沿斜視場景投影，不是畫在螢幕上的正圓。
- 牆壁與地圖邊界會截斷橙色區域。射程保持直線地面距離 5，不變更傷害、行動次數或敵方規則。
- 青綠格仍是可移動範圍；橙圈與「可攻擊」標示則代表當前可以直接射擊的敵人。
- 滑鼠指向敵人時顯示瞄準連線與「可攻擊／超出射程／牆壁遮擋／本回合攻擊已用完」等原因。無效目標不消耗攻擊次數。
- 移動中暫不顯示攻擊區，抵達後更新；攻擊次數用完、敵方回合、戰鬥結束時不保留可射擊提示。
- `in_attack_area()` 同時供實際射擊和輪廓取樣使用；`can_attack()`／`attack_status()` 是不修改遊戲狀態的查詢。輪廓只在角色站位改變後重算，牆角額外補射線以截斷遮擋邊緣。
- 新增五項測試涵蓋直線及對角邊界、牆與地圖遮擋、預覽不消耗行動、無效原因，以及投影區域與移動後更新。 全工程 18 項測試、106 項斷言通過。
- 實際視窗確認橙色射程、青綠移動格、可攻擊敵人，以及攻擊後提示隱藏、下一回合恢復均正常。
