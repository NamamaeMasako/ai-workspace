# 多日關係與據點暴露原型（沿用 Godot_完整一天原型 入口）

Godot 4.6.3 standard。本版由已驗收的完整一天延伸：早餐 → 採購 → 下午一次行動 → 晚間打工或留家 → 當日結算 → 下一天。資料夾維持原名，避免既有入口失效。原本早餐、潛行戰棋與酒館的獨立原型保留。

## 開啟與操作

匯入本資料夾 `project.godot` 後 F5，或用 Godot `--path <此資料夾>`。視窗 1280 × 800。

- 右上「紀錄」隨時查看五條關係、四組暴露、分級、今日變化、睡後預估、過往每日快照與逐筆原因；開啟期間暫停目前小遊戲和 QTE，關閉後繼續。
- 結算按「睡一覺，開始第 N 天」會保留本輪累積。沒有強制結束天數，建議先比較 7～10 天。
- R 或「新一輪」會先確認，確認後回到初始值並更新早餐自動檔；手動檔保留，不會一起清除。
- 已加入早餐前自動存檔與安全時點手動存讀檔。啟動先顯示標題選單，不會先覆蓋舊進度；可繼續自動檔、讀取手動檔或開始新遊戲。

## 一天能做什麼

1. 早餐：兩輪，每輪 10 秒，方向鍵或畫面按鈕接一項話題。對話不限時。錯誤／逾時失去該輪，不扣關係。一般閒聊不加分；第二輪「今天能一起吃早餐……」（←↑↓）是情感交流佔位，完成後 +1。兩輪後採購。
2. 採購：固定品項 $10；額外茄子 $5、蘋果 $4、茶葉 $3。畫面顯示總額和持有款，餘額不足不能確認，可取消額外品項。餘額低於 $22 時右上提供「測試補款 +$50」，保留當前早餐進度並記錄補款；這不是正式收入。
3. 下午只選一項：
   - 調查奶奶故居：沿用自由探索、背後暗殺、被發現切回合戰鬥。WASD／方向鍵或點地面；靠近守衛背後停下 E 暗殺；戰鬥點地面移動、點敵人射擊、空白鍵結束回合。返家前確認，戰鬥中不能離開。漏掉線索可改天重訪，已取得的線索跨日保留。
   - 據點支線：每組有兩項一般支線（關係 +8／暴露 -20）、一項關鍵支線（關係 +10／暴露 -35），依序提供，每項一輪只能完成一次。用簡短佔位畫面確認完成，未寫正式情節。答應後放棄 -4，沒有選任務不扣分。
   - 店內消費：測試價 $10、關係 +1，同據點每日最多一次，完成後到晚上。
   - 安全屋休息：洛芙休息，諾亞照常採購，不另加關係，方便快速比較晚間成長。
4. 晚上：
   - 薇斯帕酒館打工：沿用四張非酒精飲料訂單。1／2／3 選材料、Enter 送出／下一單、Backspace 倒掉。零送錯 +3、送錯 1～2 次 +1、3 次以上 -1；倒掉重做不算送錯。工資仍是佔位公式 `max(0, 20 + 正確杯數 × 5 - 送錯次數 × 2)`。
   - 早餐聊到想吃茄子，採購也買茄子，當晚打工便當使洛芙與諾亞 +2。每天重置今天的喜好；未接到或未買不扣分。
   - 留在安全屋：讀完佔位對話，洛芙與諾亞 +4、無工資，只結算一次。
5. 結算：顯示金錢流向、五條關係、四組據點暴露與睡後預估；按睡一覺才對仍開放據點各加 6，記錄在當日夜間後，再進下一天。

## 已確認的關係測試規則

來源為生前本次核可的數值；規則版本 `relationship-v1`。數值仍可依試玩調整。

| 數值 | 據點 NPC | 洛芙與諾亞 |
|---|---|---|
| 0～19 | 疏遠 | 生疏 |
| 20～39 | 普通 | 熟悉 |
| 40～59 | 友好 | 友好 |
| 60～79 | 信賴 | 親密 |
| 80～100 | 摯友 | 深厚羈絆 |

- 初始：諾亞 25；薇斯帕、津留、波爾三兄弟、希普七姊弟各 45。三兄弟和七姊弟各共用據點的一條關係，總共五條，不替莫里等其他角色新增密切度。
- 所有變動限制在 0～100，紀錄保存實際增減、原值、新值、來源與天數；封頂時不虛報完整獎勵。
- 不自動衰退。不把固定早餐、普通閒聊、漏接 QTE 當成加減分事件。
- 日常是小幅累積，支線是主要提升來源；重大劇情決定未用普通購物數值取代。
- 諾亞目前只有早餐情感話題、便當與晚間陪伴可實際累積；共同探索 +2、重大情感事件 +6～10、失約 -3～5 等已採用的設計範圍留待正式事件接入。飽食度、飢餓打工與強制醫療尚未重接，這些扣分本版不會觸發。
- 夜間目前只有薇斯帕有實際工作小遊戲；其他據點透過下午消費與佔位支線測試，沒有用酒館小遊戲冒充其他工作。

## 試玩比較與可驗證的預期

目標：讓生前比較 7～10 個遊戲日內「工作維持支援」「陪伴諾亞」「完成支線」的累積速度，尚不宣稱整體平衡完成。

- 十晚都留家、不取其他加分：諾亞 `25 + 10 × 4 = 65`，達親密；NPC 均 45，沒有自然衰退；不買額外品項時金錢正好從 100 到 0。
- 十晚零失誤打工，且每天都記住並準備茄子便當（危險後，下午先處理看守）：諾亞 `25 + 10 × 2 = 45`；薇斯帕 `45 + 10 × 3 = 75`；每日採購 15、工資 40，金錢為 350。不另計情感早餐話題。
- 同一據點兩個 +8 與一個 +10 支線、再四次良好打工：`45 + 8 + 8 + 10 + 4 × 3 = 83`。本版能直接測這個例子的是薇斯帕。

試玩時關注：是否覺得反覆早餐或訂單過於重複、是否容易理解加分來源、是否願意為陪伴放棄收入、支線是否過快讓關係跳級。價格、任務量、主線總天數與結局判斷都尚未平衡。暴露數值以下方 exposure-v1 為準。

## 狀態所有權與重置

- `scripts/RelationshipRules.gd`：統一門檻、初始值與關係增減；經濟測試參數亦集中於此。不是可變的遊戲紀錄。
- `scripts/DaySession.gd`：本輪唯一持有者；跨日保留天數、金錢、五條關係、四組暴露、不可逆的失去據點紀錄、完成支線 ID、已得線索、每日快照及逐筆變化紀錄。`next_day()` 只接受結算階段，先對開放據點結算自然上升，再清除當日採購、喜好、工作結果、當日突破通行資格與暫存場景狀態。`reset()` 才清空整輪。
- `scripts/DayFlow.gd`：場景內流程協調者，無新增 Autoload；畫面不持有另一份正式關係。確認／紀錄視窗暫停並恢復局部畫面；舊畫面留在父節點下 queue_free，轉場 generation 阻擋過期回呼。
- `stages/`：早餐、探索與工作局部模型；結果由 Session 的階段方法一次性接受。採購只扣一次、支線獎勵不可重領、下一天不重複跳轉。
- 舊壓力示意（基礎 +5、被發現 +3、通訊器 -2）已停用，不疊加進本輪暴露值；通訊器仍可取得及跨日保留。早餐減緩、戰敗額外增量、遠端補給與正式結局判斷留待下一版定數值。

- 洛芙回合且仍有攻擊次數、已停止移動時，地面橙色半透明區域與外框顯示當前射程；沿斜視場景投影，不是畫在螢幕上的正圓。

- 青綠格仍是可移動範圍；橙圈與「可攻擊」標示則代表當前可以直接射擊的敵人。
- 滑鼠指向敵人時顯示瞄準連線與「可攻擊／超出射程／牆壁遮擋／本回合攻擊已用完」等原因。無效目標不消耗攻擊次數。
- 移動中暫不顯示攻擊區，抵達後更新；攻擊次數用完、敵方回合、戰鬥結束時不保留可射擊提示。
- `in_attack_area()` 同時供實際射擊和輪廓取樣使用；`can_attack()`／`attack_status()` 是不修改遊戲狀態的查詢。輪廓只在角色站位改變後重算，牆角額外補射線以截斷遮擋邊緣。

- 實際視窗確認橙色射程、青綠移動格、可攻擊敵人，以及攻擊後提示隱藏、下一回合恢復均正常。


## 據點暴露規則 exposure-v1（2026-11-23）

生前核可的初輪數值，密切度增減保持原版。

| 暴露度 | 分級 | 進入方式 |
|---|---|---|
| 0～29 | 平靜 | 正常使用 |
| 30～59 | 警戒 | 正常使用，有分級與跨日提示 |
| 60～79 | 危險 | 洛芙下午須先突破看守，才能執行原本行動 |
| 80～99 | 嚴密 | 關係至少友好（40）仍可突破；低於 40 提前失去據點 |
| 100 | 失守 | 不分關係，據點無法再使用 |

- 四據點各自初始 10；每天睡一覺跨日時各 +6，只結算一次。第一天早上 10，經過九晚後第十天早上 64，再睡一晚到 70。
- 一般處理追查支線立即 -20、關鍵支線 -35，最低 0；記錄要求減量與實際減量。完成後當晚仍照常 +6。初版沿用每組兩項一般、一項關鍵的順序，沒有無限重複支線。
- 消費、打工、普通聊天與單純清除看守不降低暴露。一般個人委託未製作，本版支線全是處理追查的佔位。
- 失去據點是單獨且不可逆的本輪紀錄；關係後來回升也不重開，不能向已失去的據點領取支線或消費。R 確認開始新一輪才恢復。
- 危險據點選支線或消費會先轉進沿用的戰棋測試場景，洛芙對兩名守衛作戰；清除全部敵人，上方「進入據點」才可按，接回原選擇的協助／消費，不另占第二個下午。
- 也可選據點卡的「處理看守」，只花一個下午打通今日路線。沒有關係／暴露獎勵，跨日資格消失。
- 洛芙維持晚上留家。若酒館仍是危險／嚴密且洛芙下午沒有處理該處看守，晚間諾亞打工按鈕禁用並顯示原因；下午成功突破過酒館，或支線讓暴露降至 60 以下，當晚可工作。
- 突破中可撤退並結束下午；沒有進入據點，不收消費款、不發任務獎勵，也不算接受任務後失約。戰敗額外暴露尚未定值，暫不加。
- 突破暫時沿用測試場景與敵人，不代表每個正式據點都有相同格局或敵人。失守後 NPC 遠端補給、醫療特殊處理與正式劇情尚未接入。

數值驗證：不處理經過十天為 70、十四天 94、十五天 100；第六天處理一次一般支線，十天後該據點 50、其餘 70。關鍵任務單次可降 35；太早處理可能降到 0，使部分降幅未用到。這是十日取捨測試，不代表正式主線長度或平衡已完成。

`ExposureRules.gd` 集中門檻與定值；`DaySession.gd` 唯一修改暴露、失去狀態和日誌；`DayFlow.gd` 顯示預估並協調突破與原行動，不用 UI 自行保存另一份暴露。沒有新增 Autoload；存讀檔使用下方 schema 1 純資料快照。

新增 13 項暴露測試，涵蓋跨日只加一次、十／十五日累積、支線實際減幅與封底、消費不降、80／40 邊界、100 失守、不可逆、新一輪重置、突破成功及撤退、夜間派工限制、當日通行資格重置及舊壓力數值不疊加。

【情節評估：可採用作原型佔位】看守突破僅承接已確認的進入限制，維持洛芙下午行動、晚上留家及諾亞夜間工作的安排；未新增正式據點被攻陷情節、角色傷亡或故事結局。


## 存讀檔 schema 1（2026-11-23）

### 使用方式

- 開啟遊戲先顯示標題選單：自動檔與手動檔各一格，標示天數、時點、金錢、諾亞關係與保存時間。尚無存檔時讀取按鈕停用。單純開啟遊戲不會先寫第 1 天、蓋掉原本存檔。
- 開始新遊戲會先保存第 1 天早餐前；之後每次從當日結算按睡一覺，在自然暴露結算完、建立新一天狀態後，自動保存下一天早餐前。
- 手動保存／讀取可在四種時點使用：早餐尚未開始、下午安排、晚上安排、當日結算。入口是右上「存讀檔」。已開始的早餐 QTE、採購、探索、突破戰鬥、據點行動、打工及安全屋對話中停用。
- 手動檔與自動檔互相獨立。讀取較早的手動檔，不會立即覆寫較晚的早餐自動檔；之後真正進到下一天才更新自動檔。
- 遊戲中讀取會確認取代目前未保存的進度，取消就繼續；新遊戲也會確認更新自動檔，手動檔仍保留。
- 關閉時不另做隱藏存檔；重開後可回到最近的早餐自動檔或你明確保存的手動時點。

### 保存內容與還原語意

包含天數與階段、金錢與當日收支、五條密切度、四組暴露、失去據點、完成支線、線索與通訊器、採購與便當旗標、今日已突破路線、當日基準值、工作結果、每日快照及逐筆關係／暴露紀錄。

存檔不包含 Node、信號、Callable 或局部小遊戲執行狀態。還原時先檢查全部資料，再建立新的 Session，最後才替換目前狀態及重建對應安全畫面。讀檔不呼叫採購扣款、完成任務、發薪、加密切度或跨日方法；從當日結算讀回，仍只會在真正按睡一覺時增加一次自然暴露。

### 檔案位置與保護

- 固定 Godot custom user directory：`YidiaoTonghuaPrototype`，不依視窗名稱改變。
- 存檔位置 `user://saves/auto.json` 與 `user://saves/manual.json`。Windows 本機對應 `%APPDATA%/YidiaoTonghuaPrototype/saves/`。這些是各設備的本機遊玩紀錄，不在 workspace repo，不會隨 source commit。
- 每次先寫 `.tmp`、flush 並檢查，再替換主檔；已存在的有效主檔先保留為 `.bak`。檔案損壞時可讀上一份完整備份，介面會明確標示。
- 錯誤／不支援版本的原檔不會在讀取時被修改；日後明確保存時先封存到 `.rejected_<識別碼>`，不覆蓋既有好備份。寫入失敗保留目前遊玩狀態，顯示原因。
- schema 1 同時記錄遊戲 ID、密切度與暴露規則版本；驗證整數、範圍、四據點／任務 ID、失去據點一致性、歷日序號、日誌與當日收支。沒有既有磁碟舊版需遷移；不相容格式明確拒絕。

### 所有權與驗證
