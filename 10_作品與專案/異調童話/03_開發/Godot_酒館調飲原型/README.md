# 薇斯帕酒館：無酒精調飲原型

Godot 4.6.3 standard 獨立工程。諾亞依訂單選材料製作飲料，使用紅茶、牛奶、珍珠三種材料；做錯可倒掉重做，不判定倒入份量、材料加入順序或速度。

## 開啟與操作

匯入本資料夾的 `project.godot`，按 F5；或以本機 Godot 執行 `--path <本工程資料夾>`。

1. 按「開始工作」或 Enter。
2. 依右側訂單，點下方材料按鈕；左側配方本可隨時參考，杯中顏色、珍珠與文字會隨內容改變。
3. 按「送出飲料」。正確則客人收下，按「下一位客人」；錯誤則退回，保留原訂單。
4. 做錯可按「倒掉重做」清空杯子。若只是少加一樣材料，也可補入後再次送出。
5. 完成四張固定訂單後，按「完成工作，查看結算」。

快捷鍵：1 紅茶、2 牛奶、3 珍珠，Backspace 倒掉、Enter／空白鍵執行右下主要操作、R 重新開始。每種材料最多加入一次，重複點擊不會變成重複份量。

## 測試配方與訂單

| 固定訂單順序 | 飲品 | 材料 |
| --- | --- | --- |
| 1 | 紅茶 | 紅茶 |
| 2 | 奶茶 | 紅茶＋牛奶 |
| 3 | 珍珠紅茶 | 紅茶＋珍珠 |
| 4 | 珍珠奶茶 | 紅茶＋牛奶＋珍珠 |

全部為無酒精飲料。固定順序與四張單是便於試玩、涵蓋四種配方的原型安排；正式訂單數、隨機性及其他材料尚未定案。

## 重做與結算的暫定規則

- 倒掉不扣分，也不消耗材料庫存；空杯不接受送出，不計送錯。
- 錯誤飲料送出後仍留在同張訂單，可以修正或倒掉重做；同一杯連按送出只計一次送錯。倒掉後再做另一杯錯誤飲料，則另計一次。
- 正確飲料只能交付一次；客人收下後，杯子在該結果畫面鎖定，下一張訂單使用新杯子。
- 本版須完成所有訂單才結算；不設倒數、杯量、加入順序、庫存、價格、客人耐心或整晚失敗條件。
- 模擬工資：`max(0, 20 + 正確杯數 × 5 - 送錯次數 × 2)`。密切度測試值：零送錯 +3、送錯一至二次 +1、三次以上 -1。以上完全是待調整的原型值，不構成正式經濟與關係設計。
- 模擬結算僅顯示結果，不寫入其他原型的金錢、密切度或日期；沒有串接早餐便當、下午、其他打工場所或安全屋分支。

## 結構

- `scripts/DrinkModel.gd` 持有工作會話狀態 READY → MIXING → ORDER_RESULT → DONE、杯子、訂單、計數及模擬結果。
- `scripts/DrinkView.gd` 負責畫面與操作，沒有第二份報酬或關係資料；不使用 Autoload、不存檔，重開與 R 都回到初始會話。
- 配方、材料名稱與訂單集中於模型頂端，後續可擴充冬瓜茶、檸檬片；目前材料按鈕固定三個，擴充時須同步調整 UI。
- 場景與對白為測試佔位，不代表正式角色美術或劇情；使用簡單杯子示意混合結果，無實際倒液動畫。
