# Godot 核心循環原型

此為從既有 2.5D 故居探索範例複製延伸的獨立測試工程；畫面、線索及所有數值均為佔位，並非正式劇情或平衡。原場景探索專案保留。

## 開啟

使用 Godot 4.6 匯入本資料夾的 `project.godot`，按 F5 執行。或以 Godot 執行檔啟動時指定 `--path` 本資料夾。

## 體驗流程

1. 安全屋畫面可安排諾亞休息、同行，或早／下午到診所打工；每天只能打工一次。也可讓洛芙在安全屋待過一個時段。
2. 點「奶奶故居」前往探索。WASD／方向鍵移動，滑鼠點地板移動；接近物件後 E／左鍵互動。舊櫃有佔位線索，諾亞同行時矮桌另有佔位線索。
3. 按右下角回到城市地圖或按 Esc 結束探索，結算飽食度、打工收入並推進一個時段。晚上結束後進入隔天早上並重置打工次數。
4. 安全屋中可用食物替洛芙或諾亞補充飽食度；進食不推進時間。螢幕上方可看日期、金錢、食物與雙方飽食度。

目前數值只是測試：初始金錢 100、食物 6、飽食度 100；探索／打工各減 15、休息減 5、食物加 25、打工收入 20。食物用完後尚無購買功能；飽食度歸零後的生病與就醫、關係、據點暴露、戰鬥、完整對話與結局都尚未實作。進入探索後不能更改諾亞安排，返回時才結算；重開即重設，不支援存檔。

互動距離與移動中的互動仍沿用舊原型，使用者先前指出的問題保留至正式開發處理。

## 驗證

已接入固定版本 GUT 9.6.1。於本工程根目錄使用 Godot console 執行 `--headless --script res://addons/gut/gut_cmdln.gd -gexit`，會依 `.gutconfig.json` 執行 `tests/gut` 中的回歸測試。首次使用請先匯入工程。工具來源、skill 安裝狀態與驗證範圍見 [開發工具與驗證](開發工具與驗證.md)。

使用 Godot console 執行 `--headless --path <本資料夾> --script res://tests/core_loop_test.gd`，測試進場、結算、進食、打工限制、同行線索與跨日。
