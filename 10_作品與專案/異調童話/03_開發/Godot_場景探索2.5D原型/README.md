# Godot 2.5D 場景探索原型

## 用途

這是一個無劇情、無正式美術的 Godot 4 操作範例，用來確認固定斜視角場景、角色前後層次與室內探索操作。城市地圖、人物、家具和互動文字都是灰盒佔位內容；它不代表最終畫風或正式玩法已定案。

## 開啟方式

使用 Godot 4.x 匯入此資料夾中的 `project.godot`，再執行專案。

## 操作方式

- 城市地圖：點「奶奶故居」進入測試室。
- 移動：WASD 或方向鍵。
- 點擊移動：點擊地板區域，洛芙會朝目標移動。
- 互動：遠處左鍵點物件會讓洛芙走近；進入範圍後物件會高亮，再按 E 或左鍵確認互動。
- `Esc` 或「回到城市地圖」：返回城市地圖。
- 「重設位置」：回到場景起點。

測試室以透視梯形地板、斜視牆面、深度縮放與依地面位置排序的家具／角色，模擬 2.5D 空間感；沒有使用 3D 模型或外部素材。
