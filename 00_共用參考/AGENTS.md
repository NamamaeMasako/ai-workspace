# AGENTS.md - 共用參考區規則

此區放跨作品、跨專案會共同使用的資料。  
如果資料只屬於單一作品，請放到該作品資料夾內。

## 可放內容

- 世界觀總覽與規則
- 跨作品角色／勢力／時間線
- 共用名詞表
- 共用美術風格規範
- 共用技術流程
- AI 協作與操作流程
- 多作品共用素材規格

## 不適合放

- 單一作品限定文本
- 單一作品限定素材
- 單一專案的程式碼
- 尚未判斷歸屬的雜物（先放 `@/workspace/00_ToSort`）

## 目前主要分類

```text
世界觀/       多作品共用世界觀資料
操作流程/     OpenClaw、AI 協作、開發流程等共用操作文件
```

其中 `操作流程/` 目前可再分成：

```text
OpenClaw/     升版、維護、環境相關流程
AI協作/       Discord、規則範本、AI 工作流程
```

## 路徑規則

文件內路徑優先使用 `@/workspace/...`。  
除非是明確記錄某台設備的本機工具位置，否則不要寫死絕對路徑。

若尚未建立 Discord 相關工作規範，先到 `@/workspace/00_共用參考/操作流程/AI協作/Discord規則範本/` 複製範本，再改寫成自己的正式規則。
