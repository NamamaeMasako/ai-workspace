# AGENTS.md - 世界觀區規則

此區放跨作品共用的世界觀資料。  
一個世界觀底下可以延伸多個作品；世界觀本身不等於作品。

## 規則

- 每個世界觀獨立一個資料夾。
- 暫名要明寫 `暫名`，避免誤認為正式名稱。
- 不要把某個作品限定設定直接升格成世界共用設定。
- 新作品是否屬於某世界觀，要先確認。
- 世界二、世界三等未來世界觀應獨立建資料夾，不要混進世界一。

## 目前世界觀

```text
暫名世界一/
```

## 讀取方式

進入某世界觀時，先找該世界觀的總覽或 `AGENTS.md`。  
例如：

```text
@/workspace/00_共用參考/世界觀/暫名世界一/00_導覽與索引/世界觀總覽_暫名世界一.md
```
